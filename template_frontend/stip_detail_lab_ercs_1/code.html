Deskripsi Komprehensif Simulator

Engine Room Certification Simulator (ERCS) STIP Jakarta merupakan sarana pelatihan instruksional berskala penuh (Full Mission) yang mereplikasi sistem propulsi dan permesinan bantu kapal kontainer dan tanker modern. Dilengkapi perangkat lunak simulasi hidrolik-pneumatik dan kontrol logika berbasis mikroprosesor, laboratorium ini memfasilitasi pengujian skenario normal, kritis, hingga pemadaman total (blackout recovery).

Fasilitas ini telah diverifikasi memenuhi standar kompetensi IMO STCW 1978 Amandemen 2010 Code Section A-I/12. Seluruh aktivitas simulasi terekam secara komprehensif pada Instruktur Station untuk mendukung tahapan debriefing dan evaluasi logis taruna jurusan Teknika.

Daya Maksimal 14.280 kW @ 105 RPM
Validasi STCW DNV-GL Class A
